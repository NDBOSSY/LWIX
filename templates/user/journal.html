📡 Connecting MT5: trades are imported automatically by the sync agent running on your Windows VPS. Download mt5_sync_agent.py, configure it with your account's sync token from above, and run it on the VPS. It pushes new closed trades every few minutes automatically, and immediately when you hit "Sync Now" in the dashboard.

Why the VPS? The MetaTrader5 Python library can only communicate with a terminal running on the same machine — no cloud server can reach into your desktop directly. The sync agent runs alongside your MT5 and EA on the same Windows VPS.
